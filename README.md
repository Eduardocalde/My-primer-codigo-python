
# Mis Primeros Proyectos en Python

Repositorio de código abierto con scripts prácticos desarrollados en Python para ejercitar lógica de programación, manejo de archivos y herramientas de consola.

## 📁 Archivos del Repositorio

* **`Main.py`**: Script interactivo con menú de opciones, saludos personalizados y cálculos dinámicos.
* **`Gestor_notas.py`**: Aplicación para crear, consultar y eliminar tareas o notas con persistencia en un archivo `.txt`.
* **`Generador_claves.py`**: Herramienta de seguridad para crear contraseñas aleatorias configurables y almacenarlas de forma local.
* **`cronograma_ujieres.py`**: Automatización de logística semanal para asignación rotativa de turnos por puestos y gestión de eventos especiales.
