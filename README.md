# 🐍 Mis Primeros Proyectos en Python

Repositorio de código abierto con scripts prácticos desarrollados en Python para ejercitar lógica de programación, gestión de persistencia de datos, automatización de tareas y herramientas de consola.

---

## 📁 Proyectos Incluidos

* **`Main.py`**: Script interactivo con menú principal por consola, saludos personalizados y cálculos dinámicos.
* **`Gestor_notas.py`**: Aplicación CLI para crear, consultar y eliminar tareas o notas con persistencia de datos en archivos `.txt`.
* **`Generador_claves.py`**: Herramienta de seguridad para generar contraseñas aleatorias seguras, configurables y con opción de almacenamiento local.
* **`Conversor_datos.py`**: Conversor de unidades de almacenamiento digital (Bytes, KB, MB, GB, TB) mediante cálculo exacto en base 2 ($1024^n$).
* **`Cronograma_ujieres.py`**: Algoritmo de asignación y distribución dinámica de personal por roles operativos y días de servicio.
* **`Generar_pdf_ujieres.py`**: Módulo de exportación automatizada que maqueta y genera reportes de cronogramas en formato PDF estilizado utilizando la librería `reportlab`.

---

## 🛠️ Tecnologías y Módulos Utilizados

* **Lenguaje:** Python 3.x
* **Librerías Estándar:** `os`, `random`, `string`, `datetime`
* **Librerías Externas:** 
  * `reportlab` (para la maquetación y generación de documentos PDF)
